Windows x64 Alpha 试用版。下载 `SpektraLab_2.0.0-alpha.2_x64-setup.exe` 安装，需要支持 Vulkan 的显卡与 Microsoft Edge WebView2 Runtime。

### 更新

- 在“胶片与相纸”的相纸列表中恢复“数字中间片”选项。普通相纸、数字中间片与不印放可分别选择；反转片直接扫描。
- 数字中间片选中时不再错误高亮先前使用的相纸。由于新照片默认设置尚不能保存数字中间片模式，该模式下的“设为新照片默认”暂不可用。

### 验证与限制

- 已运行前端类型检查、ESLint、单元测试和相纸相关交互测试。
- 从安装包解出的程序使用 Nikon Z30 NEF 选择数字中间片并完成打样、Cineon TIFF 导出；文件为 5600 × 3728、16 位，附有查看 LUT。
- 本版未签名，Windows 可能提示未知发布者。与 Mac 版本的同图色彩和颗粒一致性尚未完成实测。
- 6×6 预览已渲染，后续切换画幅并导出的完整自动验收仍待确认。
